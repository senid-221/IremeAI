# IremeAI — Education Agent Platform

A bilingual (Kinyarwanda and English) AI education platform for Rwanda, designed for students, teachers, and school administrators.

## Design principles
- Responsive, accessible, mobile-first interface
- Real icons from Lucide (not AI-generated icons)
- Real educational photography from Pixabay
- Student-first, curriculum-grounded learning
- Privacy-aware student data handling

## Planned core areas
- AI learning tutor
- Teacher workspace
- School administration
- Student progress insights
- Education knowledge library

## Development
This repository is being initialized with a React + TypeScript + Vite frontend. See `package.json` for scripts.
